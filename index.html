How imagemap BBCode works

About the tool

An easier osu! image map generator

This free imagemap builder turns a visual layout into the percentage-based [imagemap] syntax osu! expects—without measuring pixels or writing each coordinate by hand.

What is imagemap BBCode?

It adds one or more rectangular links to a hosted image. osu! supports the format in places such as profiles, forum posts, signatures, and beatmap descriptions.

Read the official syntax

How do coordinates work?

Each area uses X, Y, width, and height values from 0 to 100. The editor calculates those percentages while you drag, resize, or use the precise number fields.

Is anything uploaded?

No project data is sent to an application server. Your layout stays in browser storage, while the preview loads your public image directly from its host.

Can link areas overlap?

Areas may touch but cannot overlap. Light edge snapping helps line them up, and every drag, resize, keyboard nudge, and number edit keeps the layout valid.
